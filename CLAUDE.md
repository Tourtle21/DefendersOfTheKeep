# Defenders of the Keep (Godot 4)

Roguelike co-op tower defence. Design and work queue: `DESIGN.md`. Multiplayer rules: `MULTIPLAYER.md`.

## Rules when adding content

- **Multiplayer is automatic if you follow `MULTIPLAYER.md`**: gameplay nodes join the group `net`
  (`add_to_group("net")` in `_ready`), keep host-only state in `_private` vars, route one-shot effects through
  `WeaponFx.spawn` / `DamageNumber.spawn` / `Sfx.play`, and let clients act only through `Net.net_command`.
  Run `tools/tests/net_coverage.gd` after adding a node type.
- Register new items in both `world/item_info.tres` and `world/items.gd`; new cards in `Game.CARDS`.
- Tests are scripts in `tools/tests/` (see its README). In `--script` tests never name a class_name that depends on
  an autoload; load by path. Set game state directly instead of re-gathering resources.
- Art and sound are generated by scripts in `tools/`.
